# pairwise-deinterlace

老片源一播放就出现横向锯齿，快速运动时上下场错位，暂停还有梳状纹：去隔行按固定场序，源是下场优先时整帧错位；3:2 pulldown 的 cadence 没有检测，重复场被当成运动；场景切换处仍按上一段 cadence 处理，切点出现鬼影；去隔行只做单场插值，垂直细节被抹平；运动补偿用前一帧，快速横移时出现块状拖影；可变帧率素材的时间戳不连续，场配对错乱；隔行视频的旋转元数据没有应用，画面方向反；字幕和台标被当成运动，边缘抖动；不同广播源的场序标记缺失，默认值不适用；硬件解码器输出帧缓冲，去隔行在 GPU 上重复做一次；裁剪后场边界不整，首帧半场；多片段拼接时 cadence 状态没有重置，接缝跳帧；去隔行后的帧率没有重算，播放速度不对。media/deinterlace.py 是核心，tests/test_deinterlace.py 15个红。要修的是：场序检测；cadence 识别；切点重置；垂直插值；运动补偿；VFR 配对；旋转应用；字幕保护；场序缺省；GPU 去重；裁剪对齐；拼接重置；帧率重算。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
